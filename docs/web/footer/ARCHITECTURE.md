# Work_Disk Web — Footer Architecture

## Purpose
Define the global footer as an independent presentation boundary below feature content.

## Boundary

`Feature Surface → Footer → Navigation Buttons Bot`

Footer is not Dashboard content and is not owned by the Navigation Buttons Bot.

## Responsibilities
- Present stable workspace/product information.
- Provide only explicitly contracted informational links.
- Remain in normal document flow so it follows the last content card.
- Preserve clear separation from fixed mobile navigation.

## Non-responsibilities
- No Account or Profile authority.
- No Dashboard card registry access.
- No Grid/List/Customize/Hide/Pin/Reorder state.
- No navigation visibility decisions.
- No invented product links or actions.
