# BOT-20 — Share/Repost Tool

Reusable authority-gated share/repost boundary. Destination and mode are explicit; provider owns persistence and external delivery semantics. The tool does not grant permissions, rewrite source content, or render UI.

Attack focus: destination confusion, actor spoofing, visibility escalation, cross-context leakage, stale target, replay, provider failure, attribution loss, external destination abuse, and boundary drift.
