# BOT-14 — Integration

BOT-14 is reusable across social, community and future government/enterprise relationship contexts when the domain defines an appropriate relationship scope.

Search/Filter/Sort operate on authorised relationship result sets. Mark/Unmark selects relationship records for downstream actions. Action Board may expose relationship-specific actions, but BOT-14 itself only applies its bounded relationship operations.

Notification, feed, recommendation, moderation, block/mute and messaging remain downstream/separate capabilities.
