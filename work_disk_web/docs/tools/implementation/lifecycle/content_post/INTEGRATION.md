# BOT-13 — Integration

## Intended callers
Any authorised domain that owns a post-like content creation workflow may call BOT-13. The tool is not tied to one page or account type.

## Composition
- Search discovers existing content through BOT-08.
- Filter narrows an authorised result set through BOT-10.
- Sort orders an authorised result set through BOT-11.
- Mark/Unmark selects targets through BOT-09.
- Action Board discovers applicable downstream actions.
- Edit of existing content remains BOT-07.
- Media acquisition/storage remains a separate Media Tool.
- Feed distribution remains a separate Feed capability.
- Notifications remain a separate Notification capability.
- Comments/reactions/shares remain separate capabilities.

Creation does not imply visibility, feed eligibility, notification delivery, or permission to mutate later.
