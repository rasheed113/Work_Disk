# BOT-07 — Edit ✏️

**Number:** 07  
**Category:** Lifecycle Tool Bot  
**Call model:** Multi-caller / domain-neutral

BOT-07 performs authorised edits to existing targets. It does not own domain permission or business policy.

## Locked example
Initial value: `124 pieces × rate 34`

First edit: `120 pieces × rate 34`
- Current = 120
- Original = 124

Second edit: `122 pieces × rate 34`
- Current = 122
- Original = 124
- User-facing revision list = none

## Edited marker
The marker is only applicable where the domain/presentation contract requires it, such as user-visible conversation/public content. Personal information does not automatically display an Edited marker.

## Separation
BOT-07 is not Delete, Trash, Archive, Search, Mark/selection, Notification, or Permission.

## Emoji
User-facing UI may use the real colourful `✏️` emoji. Core logic does not depend on emoji text.
